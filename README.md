### Projeto em destaque: [VidraTX](https://github.com/teixasofficial-cmd/VidraTX)

SaaS multiempresa para vidraçarias, desenvolvido de ponta a ponta. Um bot no
WhatsApp atende o cliente, a equipe monta o orçamento com cálculo automático do
vidro, e o cliente aprova respondendo "1".

- API em **Java 25 e Spring Boot 4**: JWT com perfis de acesso, isolamento de
  dados por empresa, 48 migrations Flyway e motor de cálculo testado em unidade.
- Gateway de WhatsApp em **Node.js e TypeScript**, com envio idempotente e fila
  de reenvio.
- Painel em **React e TypeScript**, responsivo para uso na obra.
- **228 testes** no backend, **266 verificações de ponta a ponta** e CI no
  GitHub Actions. Deploy com Docker Compose e HTTPS automático.
